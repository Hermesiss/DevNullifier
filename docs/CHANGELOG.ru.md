# История изменений

Все заметные изменения DevNullifier записываются в этот файл.

## [1.7.4] - Скан игр

### Изменено

- Скан игр пишет, какой лаунчер проверяется. Если лаунчер не уложился в 1 секунду, он пропускается. В сборке для разработки ход пишется в консоль.
- Сайт проекта в палитре приложения: тёплый фон, жёлтые кромки и карточки-наклейки.

## [1.7.3] - Рамка окна

### Добавлено

- Системная полоска скрыта. Свернуть, развернуть и закрыть стоят в шапке справа от настроек.
- Значок Windows собран из размеров от 16 до 256 пикселей, чтобы панель задач не сжимала большую картинку.

### Изменено

- На сайте проекта внизу свёрнут ченджлог. Английская страница читает `CHANGELOG.md`, русская — `CHANGELOG.ru.md` из файлов GitHub Pages.

## [1.7.2] - Окно о приложении

### Добавлено

- Окно «О приложении» показывает версию, короткое описание, лицензию MIT и ссылку на репозиторий GitHub.
- Ченджлог открывается на текущей версии. Более старые версии свёрнуты. Если для версии есть русская заметка, показывается она.

## [1.7.0] - Системные приложения

### Добавлено

- Вкладка «Система» сканирует временные файлы пользователя, дисковый кэш браузеров, мессенджеры, кэши шейдеров, креативные приложения и кэши лаунчеров. Выбранное уходит в корзину. Cookies, пароли и базы чатов не предлагаются.
- В кэшах инструментов появились дополнительные части. Docker и Podman могут очистить неиспользуемое без томов. Во вкладке «Игры» также GOG, Battle.net, Riot и EA.

## [1.6.0] - Вкладка игр

### Добавлено

- Вкладка «Игры» показывает установленные приложения Steam и Epic, с фильтрами по платформе, типу и последнему запуску.
- Удаление открывает диалог лаунчера. Папки игр не удаляются. У Epic нет ссылки на удаление, поэтому лаунчер открывается для ручного удаления.

## [1.5.0] - Кэши инструментов

### Добавлено

- Кэши инструментов вынесены на отдельную вкладку со прогрессом сканирования, просмотром папок и заметками о безопасности.
- У инструмента могут быть выбираемые подпапки (части) с описаниями — например, более безопасные логи Docker и небезопасный диск WSL/VM.
- Информационный диалог показывает известный каталог кэшей инструментов по категориям.

### Изменено

- Небольшой блок кэшей инструментов убран из вкладки кэша разработчика.

## [1.4.2] - Общая палитра

### Изменено

- Светлая и тёмная темы используют общую палитру DevNullifier (жёлтые основные действия, синяя навигация, графитовые поверхности) вместо стандартных цветов Vuetify Material.
- В шапке показан логотип утки; таблицы сканирования, пути, чипы категорий и полоса диска выглядят так же компактно.

## [1.4.1] - Полоса диска

### Изменено

- Полоса диска внизу показывает занятое место, найденное, выбранное внутри найденного (рядом со свободным), затем свободное место. Процент — какую долю занятого освободит удаление.
- Чипы типа проекта складываются, если в строке больше одной группы кэша.

## [1.4.0] - Сводный релиз

### Добавлено

- Свободное место. Строка состояния показывает свободное место на томе сканирования, сколько выбрано и какую долю свободного это составляет.
- Запуск администратора. Если сканирование не может прочитать папку вне профиля, Windows может перезапустить приложение от имени администратора. Установщик по-прежнему сам этого не просит.
- Повтор удаления. Неудачное или частичное удаление показывает код ошибки, и его можно повторить. В Windows строка может спросить, какой процесс держит файл.
- Сравнение сканов. После полного сканирования результаты говорят, что появилось, что выросло и сколько пропало с прошлого сканирования.
- Журнал удалений. Удаления записываются со временем, путём, размером и результатом. Список можно экспортировать в CSV.
- Вложенные проекты. Проект Dev Cleaner внутри другого проекта показывается вложенной строкой.
- Кэши в профиле. Dev Cleaner может показать известные кэши инструментов в домашней папке, не обходя проекты. Отсутствующие пути пропускаются.
- Свои правила. Пользовательские категории Dev Cleaner и ключевые слова AppData хранятся рядом со встроенными списками и попадают в следующее сканирование.
- Пресеты категорий. Dev Cleaner может переключиться только на восстанавливаемые кэши или включить все текущие категории. Ручной выбор всё равно сохраняется.
- Прогресс скана. Идущее сканирование показывает, сколько папок открыто и какой путь текущий, вместе.
- Группы приложений. Результаты AppData в Local, Roaming или LocalLow сворачиваются в одну строку на приложение. Выбор этой строки выбирает просканированные папки внутри неё.
- Фильтры таблиц. Обе таблицы результатов можно искать по пути и фильтровать по категории. Dev Cleaner показывает тип проекта. Строка может открыть свою папку или скопировать путь.
- Детали совпадений. Строки AppData показывают совпавшее ключевое слово. Строки Dev Cleaner показывают категорию и шаблон.
- Возраст и размер. Минимальный возраст и размер оставляют более новые или маленькие строки в списке, но «выбрать все» их пропускает.
- Маски путей. Маски путей пропускают совпавшие папки в обоих чистильщиках, а маска без слэша пропускает папку, в которой есть такой файл. Эти пути нельзя удалить.
- Защищённые пути. Дополнительные защищённые папки пропускаются при сканировании и не удаляются.
- Безвозвратное удаление. Необязательное безвозвратное удаление, по умолчанию выключено. Выбранное по-прежнему уходит в корзину, пока этот переключатель выключен.
- Предупреждения чистильщика. Предупреждения Dev Cleaner, число совпадений и относительные даты на английском и русском.

### Изменено

- Экран настроек. Язык, тема, канал обновлений, безвозвратное удаление, пороги, защищённые пути и исключения собраны на одном экране настроек.
- Параллельный размер. Размеры папок считаются до четырёх сразу. Одна папка по-прежнему измеряется так же, а остановленное сканирование останавливает обход.
- Безопасное удаление. Выбранные файлы и папки уходят в корзину. Удалить можно только пути из текущего сканирования. Корни дисков, профиль пользователя и каталог данных приложения отклоняются.
- Символические ссылки и соединения Windows не обходятся. Файлы кэша вроде `.eslintcache` можно удалить.
- Dev Cleaner оставляет на месте результаты экспериментов, настройки редактора и конфигурацию проекта. `vendor/` удаляется только если есть `composer.lock`. Вложенные пакеты монорепозитория сканируются.
- Глубина AppData «Все» сканирует без ограничения. Имена папок совпадают с ключевым словом в начале или в конце, поэтому `Templates` не считается временной папкой.
- Проверка обновлений использует ленту релизов GitHub. Установщик Windows больше не запрашивает права администратора.

### Исправлено

- Подсчёт размера папки продолжается, если один файл или папку нельзя прочитать.

## [1.1.0] - Dev Cleaner

### Добавлено

- Dev Cleaner: очистка временных папок разработки
- Фильтрация по шаблонам имён
- Фильтрация по категориям (кэш, модули, сборки и так далее)
- Глубокое сканирование каталогов проектов
- Что ищется:
  - node_modules (зависимости Node.js)
  - .cache (кэши приложений — Babel, ESLint и другие)
  - Library/Binary/Intermediate (артефакты Unity и сборки)
  - Папки сборки (target, dist, build)
  - Кэши пакетных менеджеров (npm, yarn, pip)

### Возможности

- Поиск по шаблонам с настраиваемыми шаблонами
- Безопасное удаление восстанавливаемых папок
- Глубокое сканирование каталогов проектов

## [1.0.0] - Очистка AppData

### Добавлено

- Очистка AppData: папки AppData в Windows
- Умное сканирование: рекурсивный поиск кэша, временных и лишних файлов
- Размеры папок в читаемом виде
- Выборочное удаление: можно выбрать, какие папки удалить
- Настраиваемая глубина сканирования

### Возможности

- Очистка папок AppData (Local, Roaming, LocalLow)
- Временные папки, кэш, аварийные дампы, ожидающие файлы, журналы
- Безопасное удаление с подтверждением

### Стек

- Electron + Vue 3 + Vuetify 3
- Node.js для операций с файловой системой
